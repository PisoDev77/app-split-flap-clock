# 보상형 광고로 배경 효과 풀기 — 계획

2026-10-14 결정. 상태: **계획만, 코드 시작 전.** 출시(프로덕션) 뒤에 광고를 붙인다.

## 왜 이렇게
- 시계는 오래 켜 두는 화면이라 배너 광고는 거슬림 → 보고 싶은 사람만 보는 **보상형 광고**
- 웹 광고(AdSense·Ad Manager)는 내 도메인이 필요함. `netlify.app` 주소로는 승인 안 됨, 도메인 구입은 비용 0원 원칙에 걸림 → **앱 광고(AdMob)**. 앱 광고는 도메인 없이 Play 앱 기준
- 지금 앱(TWA)은 크롬이 사이트를 띄우는 구조라 앱 광고를 못 띄움 → 앱을 **웹뷰 앱**으로 바꿔 만든다 (같은 패키지 `com.piso.splitflapclock`, 같은 업로드 키 → 기존 앱 업데이트)

## 규칙 (사용자에게 보이는 것)
- 무료: `particles`(파티클), `none`(없음)
- 잠금: `stars`·`snow`·`rain`·`bokeh`·`aurora` 5개
- 광고 1번 보면 **1시간** 동안 잠긴 효과를 마음대로 바꿈
- 1시간이 지나도 **켜 둔 효과는 그대로**. 다른 잠긴 효과로 바꿀 때만 다시 광고
- 광고가 없으면(채울 광고 없음·오류) **그냥 풀어 줌**. 사용자 탓 아님
- 위젯·embed·공유 링크로 들어온 효과는 잠그지 않음(공유 링크는 미리보기로 봄)
- 잠금 상태는 기기 저장(localStorage). 뚫려도 신경 안 씀
- 웹사이트(브라우저)로 온 사람: 광고를 띄울 수 없음 → 무료로 둘지 "앱에서 풀기" 안내를 띄울지 **나중에 Piso 결정**

## 단계
### 0. 출시 (지금)
- 크몽 비공개 테스트 대행 → 프로덕션 신청 → 승인 → 8 (1.6) 프로덕션 출시. hub `docs/hq/KMONG.md`

### 1. 웹 쪽 잠금 화면 (출시 기다리며, 광고 없이)
- `src/composables/useEffectUnlock.ts` 새로: `unlockedUntil` 저장, `isLocked(effect)`, `requestUnlock()`
- `requestUnlock()`은 광고 다리(bridge) 하나만 부름: 앱이면 `window.AndroidAds.showRewarded()`, 아니면 지금은 바로 풀기(기능 숨김 상태)
- 효과 고르는 곳 3곳에 자물쇠 표시: `SettingsView.vue`, `HomeView.vue`, `StudyView.vue`(·`CountdownView.vue` 확인)
- 잠긴 효과를 누르면 작은 창: "광고 1번 보고 1시간 동안 모든 효과 쓰기" [광고 보기] [닫기]. 남은 시간은 창 안에만 작게
- **기능 플래그로 꺼 둔 채 배포**(앱 광고가 붙기 전엔 아무것도 안 잠김). 화면 확인은 로컬에서
- 한/영 문구 둘 다

### 2. AdMob 준비 (Piso가 함, 프로덕션 승인 뒤)
- AdMob 가입(무료, 브랜드 계정 권장) → 앱 추가(Play에 올라간 앱 검색) → 보상형 광고 단위 만들기
- 앱 ID·광고 단위 ID는 비밀값은 아니지만 Public 저장소엔 안 씀 → 앱 빌드 폴더(`split-flap-twa/` 쪽, git 밖)에만
- 개발 중엔 Google 테스트 광고 ID만 사용(실제 광고 직접 누르면 계정 정지 위험)

### 3. 웹뷰 앱 만들기 (Claude)
- 새 안드로이드 프로젝트(Kotlin, WebView 하나): 사이트 주소 로드, 뒤로 가기, 전체 화면, 화면 켜두기, 오프라인 화면
- AdMob SDK + Google의 "WebView API for Ads" 등록
- JS 다리: 웹 `window.AndroidAds.showRewarded()` → 광고 → 보상 받으면 웹에 `onRewarded` 알림 → 웹이 1시간 풀기
- 버전 코드 9 이상, 같은 업로드 키로 서명(서명은 Piso가 `[맥]`에서)
- 확인: 에뮬레이터·Piso 폰에서 테스트 광고로 끝까지

### 4. 문구·정책 고치기 (광고 켜는 날 같이)
- "광고 없음" 문구: `src/data/pages.json`(홈·위젯), `src/views/WidgetView.vue`, 스토어 소개 글(한/영)
- 스토어 그래픽 이미지 새로(글자가 그림 안에 있음)
- 개인정보처리방침 `src/views/PrivacyView.vue`: AdMob 광고 ID 사용
- Play Console: "광고 포함" 예, 데이터 보안 양식(광고 ID), 콘텐츠 등급 다시 확인
- `app-ads.txt`: 사이트 루트에 올리기 시도(`public/app-ads.txt`). netlify 주소에서 인정되는지 확인 필요. 안 돼도 광고는 나옴(일부 줄 수 있음)

### 5. 켜기
- 기능 플래그 켜기 → 사이트 배포 → 앱 업데이트 비공개 테스트 → 프로덕션
- 1~2주 뒤 AdMob 숫자 보기: 하루 광고 본 수, 수익. 너무 거슬린다는 리뷰가 있으면 잠금 개수·시간 조정
