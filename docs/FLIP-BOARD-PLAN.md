# 플립 보드 — 설계

2026-10-15 Piso와 시안으로 정함. 앱의 주인공은 **플립되는 판**. 판에 띄울 것을 고른다: 시계 · D-day · 타이머 · 문구.

## 화면 규칙 (네 모드 공통)
- 위: 판(플랩). 아래: 모드 버튼 줄(시계 · D-day · 타이머 · 문구), 늘 보임. 안내 문구로 설명하지 않는다
- 판 아래엔 **자주 바꾸는 것만**. 한 번 정하면 잘 안 바꾸는 것(24/12시간, 도시, 배경, 테마)은 설정 화면
- 여러 개 중 고르기: 판 위 이름 옆 ▾ → 판 위에 겹쳐 뜨는 목록(✓ 지금 것, 오른쪽에 짧은 정보, 맨 아래 흐리게 "새 …" "지금 것 고치기"). 고르면 닫히고 판이 넘어감. 바깥·Esc로 닫힘
- 고칠 때는 판 아래 창이 열리고, 입력하는 대로 판이 바로 바뀜(저장 전 미리보기)
- 전체 화면에서는 모드 버튼 줄을 숨김
- 고른 모드·목록은 기기 안(localStorage)에만. 서버·수집 없음
- 사이트 첫 화면(`/`)의 기본 모드는 시계 → 검색에 잡힌 "온라인 시계" 내용 그대로. 모드를 바꾸면 다음에 열 때 그 모드

## 모드별
| 모드 | 판 | 판 아래 한 줄 | 조절 |
|---|---|---|---|
| 시계 | 지금 그대로(도시·시:분:초) | 날짜 | 없음 |
| D-day | 이름(6자) / 남은(지난) **시:분:초**, 매초 넘어감 | `D-29 · 2026. 11. 13 (금)`, 며칠째는 `412일째` | 이름 ▾ 목록, 고치기 창(빨리 고르기·이름·날짜·남은/지난·매년 반복) |
| 타이머 | 이름 / 남은 시간 | 돌 때 `오후 3:42에 끝나요`, 멈춤 `멈춤 · 12:30 남음` | ↻ 처음으로 · ▶/❚❚ · +1분, 이름 ▾ 목록(집중 25·휴식 5·라면 3·공부 50) |
| 문구 | 두 줄 × 8자 | — | 저장한 문구 ▾, ✎ 고치기(두 줄 입력·글자 수·빨리 고르기) |

- D-day 기본값: 비어 있으면 "새해"
- 타이머는 끝나는 시각을 저장 → 새로고침해도 이어짐. 끝나면 판 "끝", 소리 3번·진동

## 코드
- `src/composables/useBoard.ts`: 모드, D-day·타이머·문구 목록 저장/불러오기, 계산
- `src/components/board/`: `ModeBar`, `BoardPicker`(▾ 목록), `DdayBoard`, `TimerBoard`, `MessageBoard`
- `src/views/HomeView.vue`: 시계 모드는 기존 화면, 다른 모드는 위 컴포넌트
